# البروفايل الرقمي — ميس دعاء البحراوي

## الملفات
- `index.html`: هيكل الصفحة والمحتوى العربي والإنجليزي.
- `styles.css`: الألوان والتنسيق والتجاوب مع الموبايل.
- `data.js`: مرجع البيانات الأساسية (الاسم والهاتف والعنوان والروابط).
- `script.js`: تفاعل قائمة التنقل على الهواتف.
- `assets/profile.jpg`: نسخة من الصورة المرفقة الأصلية دون تعديل مقصود.

## التشغيل
1. فك ضغط الملف المضغوط.
2. اترك مجلد `assets` بجانب الملفات كما هو.
3. افتح `index.html` في المتصفح لمعاينة الصفحة.

## التعديل
- الألوان موجودة أعلى `styles.css` في المتغيرات `--burgundy` و`--dark` و`--soft` و`--mauve`.
- لتغيير رقم واتساب، عدّل روابط `wa.me` ورابط `tel:` في `index.html` وبيانات `data.js`.
- لتغيير العنوان أو رابط الخريطة، عدّل قسم `location` في `index.html` وبيانات `data.js`.
- لتبديل الصورة، استبدل `assets/profile.jpg` مع الاحتفاظ باسم الملف نفسه.

## ملاحظات قبل النشر
- أُدرج رابط الخريطة كما أُرسل، لكن لم يتم التأكد من أن الدبوس يطابق العنوان.
- لم تتم إضافة بريد إلكتروني أو حسابات اجتماعية غير مؤكدة.
- ملفات الصفحة ثابتة؛ لا توجد لوحة تحكم لتعديل البيانات عن بُعد.
- لا تضع كلمات مرور أو بيانات سرية في ملفات HTML/CSS/JS؛ هذه الملفات يحمّلها المتصفح ويمكن للزائر الاطلاع عليها.
- يمكن نشر الصفحة على استضافة ثابتة مجانية مثل GitHub Pages بعد إنشاء مستودع ورفع الملفات.

## اللون الوردي وQR
- تم تحديث لوحة الألوان إلى الوردي مع خلفيات بيضاء ولمسات وردية فاتحة.
- افتح `qr.html` بعد نشر البروفايل، وأدخل الرابط العام، ثم أنشئ الرمز ونزّله بصيغة PNG.
- لا يمكن تجهيز QR نهائي للبروفايل قبل وجود رابط منشور وثابت.
