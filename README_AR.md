# بروفايل ميس دعاء البحراوي — النسخة الوردية

## ما تم تحديثه
- أيقونات واتساب وفيسبوك والموقع على الخريطة والاتصال.
- إضافة صورة إلى كل بطاقة خدمة.
- إضافة زر تفاعلي لعرض محتوى تفصيلي عربي وإنجليزي داخل كل بطاقة.
- اعتماد الوردي مع خلفيات بيضاء ودرجات وردية فاتحة.
- الصورة الشخصية `assets/profile.jpg` منسوخة كما هي دون تعديل مقصود.

## الملفات
- `index.html`: بنية الصفحة.
- `styles.css`: الألوان والتنسيق.
- `data.js`: البيانات الأساسية.
- `script.js`: القائمة والتفاعل داخل بطاقات الخدمات.
- `assets/services/`: صور الخدمات الأربعة.

## مهم بخصوص رابط فيسبوك
لم يُقدَّم رابط صفحة فيسبوك الفعلي ضمن البيانات المتاحة. لذلك أُضيف شعار فيسبوك مع رابط مؤقت عام، ويجب استبداله بالرابط الحقيقي في `index.html` في قيمة `href` الخاصة بزر `facebook` قبل النشر. أرسل رابط الصفحة الصحيح لأربطه نهائيًا.
